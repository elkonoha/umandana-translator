Kebijakan Privasi — Umandana Translator

Terakhir diperbarui: 14 November 2025

Terima kasih telah menggunakan Umandana Translator. Privasi dan keamanan data Anda penting bagi kami. Dokumen ini menjelaskan jenis data yang dikumpulkan oleh aplikasi ini, bagaimana data diproses, serta pilihan dan hak Anda.

1. Ringkasan Singkat

Umandana Translator dirancang untuk berfungsi sepenuhnya di perangkat Anda. Secara default aplikasi tidak mengunggah atau menyimpan foto, teks, atau file Anda ke server pihak ketiga. Semua proses konversi/terjemahan dilakukan secara lokal pada peramban Anda.

2. Data yang Dikumpulkan

Tidak dikumpulkan: Konten teks yang Anda masukkan, foto, atau file lain.

Data opsional: Jika Anda mengaktifkan fitur analytics, aplikasi dapat mengumpulkan data anonim seperti statistik penggunaan fitur dan error teknis untuk meningkatkan kualitas aplikasi. Data ini tidak berisi informasi pribadi Anda.

3. Penggunaan Data

Jika analytics diaktifkan, data anonim digunakan semata-mata untuk:

  • Meningkatkan performa dan stabilitas aplikasi.
  • Mendapatkan statistik umum tren penggunaan fitur.

4. Penyimpanan Lokal

Aplikasi dapat menyimpan preferensi seperti tema dan riwayat setelan pada perangkat Anda melalui localStorage. Data ini tersimpan lokal dan tidak dikirimkan ke server.

5. Layanan Pihak Ketiga

Jika Anda mengaktifkan analytics, data teknis anonim dapat diproses oleh penyedia layanan pihak ketiga seperti Firebase Analytics. Penggunaan layanan tersebut tunduk pada kebijakan privasi penyedia.

6. Keamanan

Kami menerapkan standar terbaik pada sisi klien untuk menjaga data lokal Anda. Anda tetap bertanggung jawab menjaga keamanan perangkat pribadi Anda.

7. Hak dan Pilihan Anda

Anda berhak penuh untuk:

  • Menonaktifkan opsi analytics kapan saja melalui menu pengaturan di aplikasi.
  • Menghapus preferensi lokal dengan membersihkan cache/data browser Anda.

8. Ketentuan Terkait

Lihat Syarat & Ketentuan untuk aturan dan pedoman lengkap penggunaan aplikasi.

9. Kontak

Jika Anda memiliki pertanyaan terkait privasi, Anda dapat menghubungi kami melalui:

  • WhatsApp: +62

10. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan signifikan akan diumumkan melalui pembaruan aplikasi atau langsung pada halaman ini.
